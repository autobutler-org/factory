# Security policy

## Supported versions

factory has no releases yet. Fixes land on `main`.

## Reporting a vulnerability

Do not open a public issue. File a private security advisory:

<https://github.com/autobutler-org/factory/security/advisories/new>

Include:

- what you found and which component it affects
- steps to reproduce
- the version or commit you tested (`factory version`)
- what an attacker could do with it, and what access they would need first

We will acknowledge the report, tell you whether we consider it a vulnerability, and let you know when a fix is
out. Please give us a chance to ship a fix before publishing. If you would like credit in the advisory, say so.

## Hardening suggestions

Hardening ideas and defense-in-depth improvements that are not exploitable can go in the public tracker using
the [security issue form](https://github.com/autobutler-org/factory/issues/new?template=security.yaml).
